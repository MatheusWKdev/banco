# Sistema Bancário em Python

Projeto desenvolvido para praticar Python, lógica de programação, organização de código em múltiplos arquivos e controle de versão com Git e GitHub.

## Funcionalidades

* Cadastro de usuários
* Login de usuários
* Consulta de saldo
* Depósito
* Saque
* Logout
* Validação de email único
* Validação de saldo insuficiente
* Validação de valores inválidos em depósitos e saques

## Tecnologias Utilizadas

* Python 3
* Git
* GitHub

## Estrutura do Projeto

```text
banco.py/
│
├── main.py
├── menus.py
├── funcoes.py
├── dados.py
└── README.md
```

## Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/MatheusWKdev/banco.git
```

2. Entre na pasta do projeto:

```bash
cd banco
```

3. Execute o programa:

```bash
python main.py
```
